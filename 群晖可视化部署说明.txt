# ============================================================
# 群晖 Container Manager 可视化部署参数（填到"容器"创建页）
# ============================================================
#
# 如果你不想用 SSH/命令行，打开群晖的 Container Manager：
#   1. 注册表 → 搜索 nullpointerex/openlist-renamer → 下载（选 latest）
#   2. 映像 → 选中镜像 → 启动（或点"运行"）
#   3. 按下面参数填写：
#
# ┌── 端口设置 ──────────────────────────────────────────┐
# │ 本地端口: 24568    容器端口: 24568                    │
# └──────────────────────────────────────────────────────┘
#
# ┌── 存储空间设置（挂载影视目录）────────────────────────┐
# │ 新增文件夹 → 选你的影视目录（如 /volume1/影视）        │
# │ 装载路径: /media                                      │
# └──────────────────────────────────────────────────────┘
#
# ┌── 环境变量 ──────────────────────────────────────────┐
# │ BASE_URL   = http://10.10.10.1:5445                  │
# │ OL_USER    = admin                                    │
# │ OL_PASS    = admin                                    │
# │ TMDB_KEY   = 你的TMDB_API_KEY（必填）                    │
# │ SECRET_KEY = openlist-renamer-2026-0809               │
# │ MEDIA_ROOT = /media                                   │
# └──────────────────────────────────────────────────────┘
#
#   4. 启动后浏览器打开 http://<NAS的IP>:24568
# ============================================================
